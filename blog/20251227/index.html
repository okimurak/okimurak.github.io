2025 を振り返ります

気づいたら今年も残り僅かでしたので、振り返ります。 今年は珍しく 1 つ記事を書けました。

キャリア

  • 今年は比較的開発寄りのお仕事をしていました。目には見えないところでお役に立っていると思ってもらえれば。
    • 昨年同様、興味あるプロジェクト、企画に飛びついたのでこの仕事ができています。行動駆動キャリアは私に合っていると感じます。
  • JAWS-UG CDK 支部にて CDK ネタを登壇させていただきました。御縁があってのことでしたが、ご依頼ありがとうございました。また JAWS-UG 札幌支部には顔を出します。
  • 同僚が年のはじめに履歴書を書き直してキャリア見直していると聞きました。この活動は、その年のキャリア目標を決めるのにも良いと思ったので私も来年から始めます。

勉強

技術

  • 業務で使うので最近 React を勉強しています。新卒に入った会社でフロントエンド(JavaFX)を担当していましたが、またフロントエンドをやることになるとは。

  • UGREEN NASync DXP2800 を購入して、Docker コンテナを立ててバックアップ用のバッチ処理を作っていました。また、家のネットワークがトラブルになったこともあり、ネットワーク機器(Unifi)の監視ログを抽出するコンテナを作って Grafana コンテナで可視化しました。

    • 使っているネットワーク機器の温度が高めで、Unifi アプリから温度の時系列が見えないので、温度のメトリクスも取って可視化するのが、今後の課題です。メトリクス取れるのかは調べていない。

英語

開発寄りの仕事が増えたこともあり、海外の方とやり取りする機会が増えました。入社当初よりは英語はわかるようになりましたが、まだまだコミュニケーションを取るハードルは高いので、勉強を加速させないと。

生活

  • 軽自動車を購入しました。動機は単純で北海道にいて車でしか行けない場所が多いことが理由です。運転はまだまだですが、行動範囲が増えたメリットが大きいです。安全第一に。

    • 搭載しているカーナビ(AVIC-RZS901ZSII) が使いにくいので買い替えを検討しているが、今のカーナビ事情はよくわからない。どなたかおすすめ教えてください。

  • ダイエット兼体力増強のため、半年前から筋トレを再開しました。当時は 70kg 近くありで、65kg が目標で、現在 66kg まで落とせました。いい感じですね。

    • 北海道来てからソフトテニスを再開したので還暦迎えてもできるように、今後も継続していきたいですね。
    • 冬は運動不足になりがちなので、スキーをやろうと計画しているのですが、今年は雪が少なくて近所のスキー場がオープンしていないのが悩みです。

購入したもの

NAS は省略

Cloud Gateway Fiber

Unifi の L3 が欲しかったので購入。家庭ネットワークに接続している機器が可視化できました。NVR を兼用していますが、2TB のモデルではなく、No Storage モデルを選択し、M.2 SSDトレイと SSD 2TB を別途購入して使っています。当時はこの組み合わせの方が安価でした。SSD の有無関係なく 55-60℃ あるのが少し気になっています。

残りはアクセスポイントを WiFi7 に更新することがありますが、接続元の WiFi7 に対応した機器が少ないので一旦見送っています。

ZallBall

詳細は今年の記事を見てください。結局テンティングせずに使っていますが、満足しています。

REYS ホエイプロテイン (カフェオレ風味)

明治ザバスホエイプロテインから乗り換えました。最近のザバスは水に溶けにくくなったこと、こちらのほうが安価なことが理由です。味も美味しく、水にもよく溶けるのが良いです。

カービィのエアライダー

幼少期を取り戻せました。この理由だけで買ってよかったです。エアライドやスマブラ、マリオパーティなどを友達と家で遊んだのが本当に懐かしいですね。

伊藤園 野菜ジュース

災害備蓄権、普段飲む用です。無難に美味しい。

山崎実業 マグネット風呂イス SH35 ホワイト

風呂の壁に磁石でつけられるのが便利。風呂床掃除が楽。高さ、色の種類があるので注意。
